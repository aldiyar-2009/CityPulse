# 🔍 Как проверить данные в MongoDB Atlas - Пошаговая инструкция

## 📌 Способ 1: Через веб-интерфейс (САМЫЙ ПРОСТОЙ)

### Шаг 1: Откройте MongoDB Atlas
1. Перейдите на https://cloud.mongodb.com/
2. Войдите в аккаунт

### Шаг 2: Найдите ваш кластер
Вы увидите кластер **"CityPulse"** в списке

### Шаг 3: Нажмите "Browse Collections"
```
┌─────────────────────────────────┐
│  CityPulse Cluster              │
│  ┌──────────────────────────┐   │
│  │ [Browse Collections]     │   │ ← НАЖМИТЕ ЭТУ КНОПКУ
│  └──────────────────────────┘   │
└─────────────────────────────────┘
```

### Шаг 4: Выберите базу данных
Слева выберите базу `citypulse`

### Шаг 5: Просмотрите коллекции
Вы увидите:
- **users** - все пользователи
- **events** - все события

### Шаг 6: Кликните на коллекцию
Например, `users` - увидите всех зарегистрированных пользователей

## 🧪 Тестирование сохранения данных:

### Тест 1: Регистрация пользователя

**1. Запустите сервер:**
```bash
cd server
npm run dev
```

**2. Зарегистрируйте пользователя (используйте Postman или curl):**
```bash
POST http://localhost:5000/api/auth/register
Content-Type: application/json

{
  "name": "Тест Тестов",
  "email": "test@example.com",
  "password": "123456"
}
```

**3. Проверьте в Atlas:**
- Откройте MongoDB Atlas
- Browse Collections → citypulse → users
- **Нажмите кнопку обновления** (🔄)
- Увидите нового пользователя!

### Тест 2: Покупка билета

**1. Войдите и получите токен:**
```bash
POST http://localhost:5000/api/auth/login

{
  "email": "test@example.com",
  "password": "123456"
}
```

**Сохраните токен из ответа!**

**2. Купите билет:**
```bash
POST http://localhost:5000/api/events/purchase
Authorization: Bearer ВАШ_ТОКЕН_ЗДЕСЬ

{
  "eventId": 1,
  "price": 5000
}
```

**3. Проверьте в Atlas:**
- Откройте MongoDB Atlas
- Browse Collections → citypulse → users
- Найдите вашего пользователя
- Увидите в поле `purchasedTickets` новый билет!

### Тест 3: Добавление в избранное

**1. Добавьте событие в избранное:**
```bash
POST http://localhost:5000/api/events/favorite
Authorization: Bearer ВАШ_ТОКЕН_ЗДЕСЬ

{
  "eventId": 1
}
```

**2. Проверьте в Atlas:**
- Откройте MongoDB Atlas
- Browse Collections → citypulse → users
- Найдите вашего пользователя
- Увидите в массиве `favorites` ID события!

## 🎯 Контрольный список проверки:

После запуска сервера и импорта событий:

✅ **Коллекция events:**
- Должно быть 3 события
- ID: 1, 2, 3
- Все поля заполнены

✅ **После регистрации пользователя:**
- Появится новый документ в `users`
- Пароль будет хешированный ($2a$10$...)
- role = "user"
- balance = 0
- favorites = []
- purchasedTickets = []

✅ **После покупки билета:**
- В `purchasedTickets` появится объект с билетом
- `balance` уменьшится
- В `events` у события уменьшится `ticketsAvailable`

✅ **После добавления в избранное:**
- В `favorites` появится ID события

## 🔧 Troubleshooting:

### Не вижу данные в Atlas:
1. Обновите страницу (F5)
2. Убедитесь что выбрана база `citypulse`
3. Проверьте что сервер запущен
4. Проверьте логи сервера на ошибки

### Ошибка подключения:
1. Проверьте `.env` файл
2. Убедитесь что MONGODB_URI правильный
3. Проверьте интернет соединение
4. Убедитесь что IP адрес добавлен в белый список Atlas

### Данные не сохраняются:
1. Проверьте консоль сервера на ошибки
2. Убедитесь что токен правильный (для protected роутов)
3. Проверьте формат данных в запросе
